## Pipeline freeze — do not violate without a new bar
- `docs/FREEZE.md:9` is the contract. No edits to `unihack_catalog/` after `38db2af` except via a Bar 5 that re-runs the full acceptance table.
- Dual-pass gate is invariant: every emitted value must appear verbatim in source text (or literal unit conversion `value+uom`). Failures escalate; blanks are abstentions with reason, never guesses. Four abstention classes are the only allowed blanks.
- Do not chase `attrs/row` counts at cost of precision/provenance.
- 252-column contract: `stages.py:_canonical_252_headers()` is canonical; export uses `encoding="utf-8-sig"` so Excel renders `®`. Never change header count/order.
- `artifacts/acceptance_table.md` is generated — if it diverges from `docs/FREEZE.md`, regenerate; generated file wins.

## Frontend cockpit quirks
- `elio-frontend/src/app/app/dashboard/page.tsx` is intentionally single-file (double-nested `app/app` is Next route grouping). State/handlers/metrics/types live in chunk A ending `// __CHUNK_A_END__`; chunks B-E append per `PLAN.md:8`. Do not split without updating `PLAN.md` leaf contracts.
- `api/run/route.ts` validates 6 columns `Mfg_Part_Num,Part_Desc,Part_Manuf,E1_Brand,Unilog_Brand,DIB_Brand` with fallback `MPN,Description,Manufacturer`; writes `tmp/input_<id>.csv`, hashes with SHA-256, and cleans `tmp/`.
- Visual truth: `DESIGN.md` is canonical (brand `#2563eb`, Verified `#22c55e`, Review `#f59e0b`, mono for all data, flat-by-default, no em dashes, no `background-clip:text`). `PLAN.md` lime (`#c8d84a`) is a landing-only iteration artifact — do not propagate to cockpit without a design decision.
- `elio-frontend/AGENTS.md` is auto-generated by `next dev` from `node_modules/next/dist/server/lib/generate-agent-files.js`. Read `node_modules/next/dist/docs/` before changing Next APIs; do not hand-edit `AGENTS.md` — commit the generated version to keep tree clean.

## Gotchas
- `elio-frontend/node_modules`, `.next`, `tmp/`, `__pycache__/`, `*.pyc`, `.venv/`, `session-*.md`, `ours_output.json` are ignored or untracked; `scripts/.gauntlet_results.pkl` is an untracked evidence cache purged before seed-7 holdout; `.agents/` is vendored tooling, must not ship (`.gitignore:1`).
- `graphify-out/` and `artifacts/` are derived — never hand-edit; regenerate via `graphify update .` / `verify_everything.py`.
- `ELIO_ASSISTED=1` enables proposal layer for `scripts/regen_exports.py`; default pipeline is deterministic.
- File encoding: always `utf-8-sig` for CSV I/O; headers stripped of `\ufeff`. Powershell `Get-Content` defaults to different encoding — use Python for CSV checks.
- No `opencode.json` / CI workflows / pre-commit hooks at root. No test runner beyond `verify_everything.py` + `verification_ledger.py` — `pytest`/`jest` do not exist here.
