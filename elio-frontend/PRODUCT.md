# Product

## Register

product

## Users

Primary: Unihack judges evaluating the submission in a live demo. Secondary: catalog operations reviewers and technical evaluators who will later use the tool daily to enrich product catalogs from manufacturer evidence.

Job to be done: hand over a product catalog CSV and receive a fully enriched, evidence-traced catalog in return. Every value must be verifiable back to its source document; anything the pipeline cannot trace must be refused with a stated reason, never guessed.

## Product Purpose

ELIO enriches product catalogs from manufacturer evidence, then surfaces exactly where every value came from. It runs a deterministic enrichment pipeline over an uploaded catalog, tags every extracted attribute with its custody chain (source document, page, offset span, verbatim snippet), and abstains with a written reason when evidence is missing or conflicting. Success looks like a judge or buyer trusting the output because they can click any value and see the raw text it came from.

## Brand Personality

Precise, calm, trustworthy. Sharp and technical on the evidence surfaces, forensic without being cold. Bold and confident at the pitch moment, plain-spoken everywhere else. The product's character is integrity made visible: it would rather refuse a value than fabricate one, and the interface says so without insisting on the word "honest."

## Anti-references

- Generic AI-slop dashboards: no bento-card grids, invented metrics, gradient accents, glowing badges, or infinite pulse animations.
- Neon crypto / cyberpunk: no glow, garish gradients, or tech-larp styling.

## Design Principles

1. **Evidence over assertion.** Every number on screen traces to a real derivation from the loaded data. No static metrics, no invented percentages, no "TARGET MET" badges.
2. **Refuse with a reason.** Abstention is the product's personality: never a blank cell, always an explainable refusal.
3. **One accent, used sparingly.** Color is semantic (blue for interaction, green for verified, amber for review/refusal). It never decorates.
4. **Calm confidence.** Mono numerals, hairline rules, dark surfaces that recede so the data leads. Motion is a one-beat acknowledgment, never a loop.
5. **Plain-spoken copy.** No em dashes, no restated headings, no insisting on adjectives like "honest." The proof is in the trace.

## Accessibility & Inclusion

Baseline WCAG AA: sufficient contrast, full keyboard navigation, visible focus states, reduced-motion respected. Status is never communicated by color alone.
