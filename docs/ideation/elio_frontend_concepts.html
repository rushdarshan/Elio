ELIO Frontend — Concept Ideation

Ranked candidate feature designs and adversarial critiques for the ELIO Next.js Web Application.

Candidate Feature Designs

1. Trust-Gated Custody Panel (Visual Evidence Drawer) Rank 1 — Primary Winner

An interactive slide-over drawer that displays the custody chain when a user clicks any cell in the metrics or results grid. It shows the source URL, exact character span, and a highlighted verbatim text snippet from the raw workbook text to prove no values were hallucinated.

Adversarial Critique

Needs character-offset tracking from the Python backend. If the raw text does not contain exact matching sub-strings due to normalizations (e.g. 2x2 -> 2 ft x 2 ft), character spans must be mapped correctly to prevent mismatch highlights.

VERDICT: SELECTED FOR BRAINSTORMING
2. Live-Scoring Review Queue (Split-Pane Worklist) Rank 2 — Secondary Winner

A split-screen interface displaying flagged rows on the left and an edit form on the right. Making overrides immediately recalculates metrics (precision, coverage, abstention rates) dynamically on the dashboard, with overrides saved to decision_log.jsonl.

Adversarial Critique

Metrics recalculation must be instantaneous without triggering full pipeline re-runs (which would slow down the ops workflow). Re-computation should run as a lightweight front-end logic layer.

VERDICT: SELECTED FOR BRAINSTORMING
3. Interactive Sankey/Stream Pipeline Tracker Rank 3 — Defer

A graphical flow diagram representing the 9-stage Python DAG in real time, visualizing row volume and drop-off rates visually.

Adversarial Critique

Overly complex and visually distracting for short 2-3 second synchronous runs of small datasets. A simple progress bar combined with immediate dashboard loading is cleaner and maps better to the target audience (judges who want speed).

VERDICT: DEFERRED (Over-engineered for V1)
4. Clear-Badge Abstention Matrix Rank 4 — Integrate

A grid dashboard grouping all unextracted cells by their specific logical reason (e.g. missing evidence, distributor blacklist, unsupported category).

Adversarial Critique

A separate full matrix view creates layout redundancy. It is cleaner to integrate these tags directly into the tabular Evidence Explorer as inline badges, allowing the user to filter the main explorer table by "Abstention Reasons".

VERDICT: INTEGRATED INTO EVIDENCE EXPLORER
